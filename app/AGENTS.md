# Angular chat spike

User-authorized training spike adapted from the official vercel/ai Angular example. Scope: one streaming chat with Angular, Express and Vercel AI Gateway. No persistence, authentication or tools.

Run `pnpm install`, `pnpm build`, `pnpm start` in app. Frontend: http://localhost:4200. Backend: http://127.0.0.1:3000.

Keep AI_GATEWAY_API_KEY server-side in ignored .env. No secrets in frontend, logs or commits. Use synthetic prompts. This authorized spike uses build and real browser verification instead of the Java PRD/ADR/TDD workflow. Never simulate successful AI responses. Preserve upstream attribution. Do not commit or push.
